`pdf.min.mjs` and `pdf.worker.min.mjs` are the upstream legacy build. `cmaps`, `standard_fonts`, and the JavaScript image decoders in `decoders` are copied from the same distribution with their licenses. `view.html` and `reader.mjs` are Hagency's own reader. It draws each page and lays PDF.js's text layer over it, so that text can be selected, copied and found, and it changes the pages' size; it installs no links, forms, annotations or scripting. The text layer's style rules and the handling that keeps a selection steady are adapted from the viewer of the same PDF.js release (`web/pdf_viewer.css` and `web/text_layer_builder.js`), under the same Apache 2.0 license. The local preview serves these resources together with the PDF and the reader's texts in the app's language. It uses no network service or stock PDF.js viewer.
